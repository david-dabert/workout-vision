**1. The script crashes when the repository path contains a space or other non-ASCII character** (`/home/user/workout-vision/scripts/import-sets.mjs:11`)
```js
const ROOT = resolve(dirname(new URL(import.meta.url).pathname), '..', 'test', 'real-phone');
```
`URL.pathname` keeps percent-encoding, so a space arrives as `%20` (an accented letter is encoded the same way). A clone under a folder like "My Projects", or under iCloud Drive ("Mobile Documents/..."), gives a ROOT that does not exist. `readdirSync(ROOT)` then throws ENOENT and the import cannot run. I reproduced it with a copy of the scripts under a folder named "my repo":
```
Error: ENOENT: no such file or directory, scandir '.../scratchpad/my%20repo/test/real-phone'
```
The fix is `fileURLToPath(import.meta.url)`.

**2. "Already in the repository" does not cover `test/real-phone/landmarks/`** (`import-sets.mjs:21-25`, README lines 24-25)
