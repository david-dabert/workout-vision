# David's sealed sets

Every set David films after 15 November 2026 comes here, never into `test/real-phone/sets*` (PLAN.md, amendment of 15 November 2026, THE DATA; David: "adopt").
It is read once, by its exam script, for a gate (Phase 1's third condition: at least 20 sets, at least 9 in 10 of the counts shown as sure exact, none shown as sure off by 3 or more).
No other script, test or agent opens a file of this folder before that read. Each read set is then listed in `exposed.json` in the same commit and joins the regression gates, never again an exam.
Labels are David's blind counts (R1), entered before the app shows its own.
