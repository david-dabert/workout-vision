Defect 1: the tour job dies before running a single tour. .github/workflows/ci.yml, "Run the tour at every setting", lines 68 to 72.
The step has no shell set, so GitHub runs it with bash -e. In
  dir="test/real-phone/tour-ci/$1x$2$([ "$3" = 1 ] && echo -reduce)$([ "$4" = light ] && echo -light)"
an assignment's exit status is that of its last command substitution. With "dark", [ dark = light ] is false, the assignment returns 1, and bash -e aborts the step.
Failing scenario: on the first setting ("390 664 0 dark") the step exits 1 before node tour.mjs runs once. The tour job is red on every push, with no shots and no results.json; nothing in the job checks "Filmer ma série" in view.

Minimal fix: || true on each substitution, or build dir with if statements.
